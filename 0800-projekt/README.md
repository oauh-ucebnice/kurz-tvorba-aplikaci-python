# Souhrnný projekt

## Cíl lekce
Vytvoř si vlastní užitečnou aplikaci.

## Klíčová témata
- kombinace syntaxe, větvení a cyklů
- práce se soubory nebo API
- dokumentace projektu

## Projektový úkol
Vytvoř program podle vlastního zájmu, například:
- deník,
- správce úkolů,
- malá databáze záznamů,
- aplikace s počasím.

Popiš svůj projekt v `README.md` a uveď, které techniky jsi použil.

# Grafické uživatelské rozhraní

## Cíl lekce
Naučit se vytvořit jednoduché grafické rozhraní pomocí `tkinter`.

## Klíčová témata
- Vytvoření okna aplikace
- Tlačítka a textová pole
- Obsluha událostí
- Zobrazení výsledku uživatele

## Projektový úkol
Vytvoř okno s:
- vstupním polem pro text,
- tlačítkem „Zobraz“,
- štítkem, který ukáže text po stisku tlačítka.

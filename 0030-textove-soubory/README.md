# Textové soubory

## Cíl lekce
Porozumět práci se soubory v Pythonu, načítat a ukládat jednoduchá data.

## Klíčová témata
- `open()`
- režimy `r`, `w`, `a`
- `read()`, `write()`, `readlines()`
- `with` pro bezpečné uzavření souboru

## Projektový úkol
Vytvoř program, který:
- přečte text ze souboru `input.txt`,
- spočítá počet slov,
- zapíše výsledek do `output.txt`.

# 0060 Git a GitHub

## Cíl lekce
Naučit se základní práci s Gitem a publikaci na GitHubu.

## Klíčová témata
- `git init`
- `git add`, `git commit`
- `git remote add`, `git push`
- základy GitHub repozitáře

## Projektový úkol
Vytvoř repozitář s:
- lekčními soubory,
- prvním commit zprávou,
- popisem v root `README.md`.

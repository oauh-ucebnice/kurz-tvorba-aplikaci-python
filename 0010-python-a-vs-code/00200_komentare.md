# Komentáře

Komentáře jsou řádky, které Python ignoruje. Slouží k tomu, aby ses v kódu rychle orientoval a ostatním vysvětlil, co program dělá.

> Komentáře nepřidávají funkce programu, ale zlepšují jeho čitelnost.

## Jednořádkové komentáře
Používáš je pro krátké poznámky:

```python
# Vypiš pozdrav na obrazovku
print("Ahoj světe!")
```

## Víceřádkové komentáře
Pokud chceš napsat delší poznámku, můžeš použít tři uvozovky:

```python
"""
Tento text je komentář.
Python ho ignoruje.
"""
```
> Ze začátku je dobré psát si komentářů hodně, protože je pro tebe všechno nové. 
> Každý komentář je řádek navíc, a je třeba ho udržovat aktuální. Zkušený programátor proto komentářů píše málo – píše kód tak, aby komentáře nepotřeboval.

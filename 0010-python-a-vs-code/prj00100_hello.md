# Hello world!

> Při výuce programování se obvykle začíná příkladem Hello world!
> Vytvoř aplikaci, která zobrazí pozdrav.


## Level 1: Pozdrav

Vytvoř skript `hello.py`, který:
- vypíše pozdrav *„Hello world!“*, nebo chceš-li, tak *„Ahoj světe!“*

## Level 2: Přidej jméno

Uprav skript:
- nejprve požádá uživatele o zadání jména,
- poté vypíše pozdrav s využitím jména, které uživatel zadal. Například: *„Hello Karel!“*

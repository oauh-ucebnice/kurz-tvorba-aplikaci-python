# Pole (list)

## Co je pole

Pole (v Pythonu se mu říká `list`) je datová struktura, do které uložíš víc hodnot najednou, pod jedním názvem.

```python
jmena = ["Karel", "Petra", "Jan"]
```

## Přístup k prvkům

Každý prvek pole má svůj index – číslo pozice, které se počítá od `0`:

```python
print(jmena[0])  # Karel
print(jmena[1])  # Petra
print(jmena[2])  # Jan
```

> Poslední prvek pole má index o jedno menší, než je počet prvků. Pole se třemi prvky má indexy `0`, `1`, `2` – index `3` by způsobil chybu `IndexError`.

## Přidání a odebrání prvku

```python
jmena.append("Eva")     # přidá prvek na konec
jmena.remove("Petra")   # odebere první výskyt hodnoty "Petra"
```

## Délka pole

```python
print(len(jmena))  # počet prvků v poli
```

## Průchod polem cyklem

```python
for jmeno in jmena:
    print(jmeno)
```

## Časté chyby
- Přístup k indexu, který v poli neexistuje – `IndexError`.
- Záměna hodnoty a indexu u `remove()` – `remove()` odebírá podle hodnoty, ne podle pozice.
- Očekávání, že pole začíná indexem `1` – v Pythonu vždy začíná `0`.

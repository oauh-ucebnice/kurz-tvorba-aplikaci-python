# Větvení a cykly v Pythonu

## Cíl lekce
Procvičit rozhodování a opakování pomocí podmínek a smyček.

## Klíčová témata
- `if`, `elif`, `else`
- `for`
- `while`
- `break`, `continue`

## Projektový úkol
Napiš program, který:
- získává čísla od uživatele v cyklu,
- vypočítá součet,
- ukončí zadávání při zadání nuly.

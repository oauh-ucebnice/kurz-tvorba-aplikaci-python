# API a webové datové zdroje

## Cíl lekce
Pochopit, jak získávat data z webu a pracovat s nimi v Pythonu.

## Klíčová témata
- HTTP požadavky s `requests`
- JSON data
- parsování a zobrazení dat
- chybové stavy

## Projektový úkol
Napiš skript, který:
- načte data z veřejného API,
- vybere několik hodnot z JSON,
- vypíše je přehledně do konzole.
